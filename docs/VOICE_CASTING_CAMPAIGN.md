# 터칭보이스 무광고 확산 캠페인 실행 키트

작성: 2026-11-19 (한국 시간). 상태: 실행 준비안. 외부 게시·메시지 발송·실제 이용자 실험은 아직 수행하지 않았다.

## 1. 캠페인과 첫 실험

캠페인: **우리 모임 목소리 캐스팅**
질문: “우리끼리 라디오를 만든다면, 누가 오프닝을 읽을까?”

개인 결과를 서로 이야기할 소재로 만들고, 참여자가 자기 모임에 자발적으로 소개하도록 한다.
목소리 유형은 놀이와 자기 탐색을 위한 해석이다. 실제 성격·나이·능력·직업 적합성을 증명한다고 홍보하지 않는다.

첫 모집 단위는 성인으로 구성된 모임 다섯 곳이다. 독서 모임 2곳, 보컬·합창 모임 2곳, 말하기·방송 모임 1곳을 가설로 시작한다. 이 숫자는 실적이나 확보된 제휴가 아니다.
운영자가 참여를 원하고 홍보·체험 모집이 허용되는 곳만 선정한다.
목표는 모임마다 자발적 참여자 5명, 총 25명의 완료 경험을 관찰하는 것이다. 달성을 보장하지 않는다.

## 2. 배포 전 필수 확인

- iPhone Safari, Android Chrome, 데스크톱에서 각각 새 이용자 흐름으로 실제 녹음부터 최종 레포트까지 확인한다. 거부된 마이크 권한, 중간 이탈 후 복귀도 확인한다.
- 무료로 제공되는 범위와 종료 조건을 운영자가 확정한다. 현재 voicereport.html의 openPreview는 서버가 not_test를 반환하면 결제 안내로 이동한다. ?free만으로 무료 제공을 보장할 수 없다.
- “1분” 같은 소요 시간은 실제 사용자 측정 전에는 쓰지 않는다. 현재 ?free는 녹음 두 번과 성격 문항 10개를 포함한다.
- 무료 초대 링크로 진입한 사람이 재공유할 때도 안내와 실제 제공 범위가 일치하는지 확인한다. 현재 voicetest.html의 shareURL은 f와 r만 전달하며 free를 유지하지 않는다. 단순히 free를 붙이면 기존 케미 화면을 건너뛸 수 있으므로 전체 흐름 확인 후 수정한다.
- 녹음 연구·개발 제공 동의 여부에 따라 저장 범위가 다르므로 “녹음은 절대 업로드되지 않는다”라고 홍보하지 않는다.
- 결과 캡처 전에 이름·나이·점수 등 숨길 항목을 안내한다. 타인의 결과·음성은 별도 허락 없이 다시 게시하지 않는다.

위 확인 전에는 아래의 무료 문구를 실제 배포하지 않는다. 아직 구현되지 않은 단체 결과판·서버 공유방·보상 기능도 홍보하지 않는다.

## 3. 바로 사용할 문구

아래 운영자 문구는 제작자 또는 제작팀 명의로만 사용한다.

### 운영자에게 보내는 체험 제안

안녕하세요. 터칭보이스 제작팀입니다.
모임에서 “우리끼리 라디오를 만들면 누가 어떤 부분을 읽을까?”를 이야기할 수 있는 목소리 유형 테스트를 만들었습니다.

녹음 두 번과 질문에 답한 뒤 결과를 볼 수 있습니다. 모임 활동으로 맞을지 소수 인원에게 먼저 체험을 부탁드리고 싶습니다. 좋은 평가나 공개 후기, 공유는 필수가 아닙니다. 맞지 않았던 해석과 불편했던 부분도 듣고 싶습니다.

허용되는 모집 방식과 게시 위치가 있을까요? 관심 있으시면 이용 범위와 개인정보 안내를 먼저 전달드리겠습니다.

### 허용된 체험·홍보 게시판용

제목: [제작자 체험 모집] 우리 모임에서 라디오 오프닝을 읽을 목소리는?

안녕하세요. 목소리 유형 테스트 터칭보이스를 만든 팀입니다.
평소 내가 듣는 내 목소리와 다른 사람이 듣는 인상이 다를 때가 있어, 결과를 보고 서로 이야기할 수 있는 테스트를 만들었습니다.

녹음 두 번과 질문에 답하면 결과를 볼 수 있습니다.
이번 체험에서 확인된 무료 제공 범위: [운영자가 검증한 범위와 기간 입력]

해본 뒤 “잘 맞은 표현 하나 / 안 맞은 표현 하나”를 알려주시면 개선에 도움이 됩니다.
성격이나 능력을 판정하는 검사는 아니며, 결과 공개와 공유는 선택입니다.
녹음 처리·저장 안내는 시작 전 동의 화면에서 확인해 주세요.

테스트: [해당 게시판용 추적 링크]
게시판 규칙에 맞지 않으면 운영 방침에 따르겠습니다.

### 실제 참여자가 원할 때 사용할 초대 문구

우리끼리 라디오 만들면 누가 오프닝 읽을까?
나는 [본인의 실제 결과/느낀 점]이 나왔어.
해보고 결과에서 맞는 말 하나, 아닌 말 하나 골라보자.
[테스트 링크]

실제 이용자가 자신의 경험으로 작성할 때만 사용한다. 제작팀이 일반 이용자인 것처럼 게시하지 않는다.

### 모임별 첫 질문

- 독서 모임: 같은 첫 문장을 돌아가며 읽으면, 어느 장면에 어울리는 목소리일까?
- 합창·보컬 모임: 내가 생각한 음색과 결과 설명은 어디서 같고 다를까?
- 방송·말하기 모임: 라디오 첫 인사와 이야기 낭독, 나는 어느 쪽을 해보고 싶을까?
- 친구 모임: 서로 알고 있던 목소리 특징과 처음 발견한 특징은 무엇일까?

실제 음성을 모임에 제출하도록 요구하지 않는다. 기존 결과만 이야기해도 참여할 수 있다.

### 카드 문구 초안

제목: 내 목소리를 한 장면에 캐스팅한다면
본문: [실제 결과 유형] / 나에게 맞았던 한 문장: [직접 선택]
마무리: 너는 어느 장면에 어울릴까?
하단: 터칭보이스 · 목소리 유형 탐색 / [짧은 링크 또는 QR]

한 화면에 읽히는 세로 카드 한 장을 우선한다. 이름·나이·세부 점수는 기본 제외를 제안한다.
“상위 1%”, “타고난 성우”, “실제 목소리 나이”, “과학적으로 성격 확정” 같은 미검증 문구는 쓰지 않는다.
카드 템플릿은 제안이며 이 PR에서 제품에 구현하지 않았다.

## 4. 채널과 접근 순서

| 우선순위 | 채널 유형 | 접촉 방식 | 게시 조건 |
| --- | --- | --- | --- |
| 1 | 기존에 관계가 있는 모임 운영자 | 평소 연락 채널에서 체험 제안 | 관계·운영자 허락이 실제로 있는 경우 |
| 2 | 성인 독서·보컬·합창·스피치 모임 | 공식 제휴 문의 또는 명시된 체험 모집 창구 | 모집 허용 확인 |
| 3 | 제작기·서비스 체험 공유 커뮤니티 | 제작자임을 밝힌 제작기와 피드백 요청 | 자기 홍보 허용 게시판 |

답이 없으면 반복 독촉하지 않는다. 거절·삭제·운영자 제한은 해당 채널의 중단 신호다.
구체적인 커뮤니티 이름과 규칙은 게시 당일 확인해 기록한다. 이 문서의 표는 허용 여부를 검증한 사이트 목록이 아니다.

## 7. 성과 기록과 판단

기록 열:
날짜(KST), 채널, 규칙 확인 URL/일시, 운영자 허락, 게시 URL, UTM source, content, 방문자, 녹음 시작자, 테스트 완료자, 최종 레포트 열람자, 공유 시도, 확인된 추천 신규 완료자, 오류, 관찰 메모

- 완료율 = 테스트 완료자 / 시작자
- 레포트 도달률 = 최종 레포트 열람자 / 테스트 완료자
- 추천 확산 계수 = 확인된 추천 신규 완료자 / 최초 완료자
- 분모가 0이면 계산 불가로 표시한다.
- 공유 버튼 클릭은 공유 시도다. 공유 성공·친구 도달·친구 완료와 구분한다.
- 추천 신규 완료자는 별도 식별·중복 제거가 확인될 때만 집계한다. 현재 계측이 부족하면 “측정 불가”로 남기고 UTM 유입 완료를 대리지표로 따로 표시한다.
- 개인별 결과와 음성 대신 필요한 최소한의 집계만 사용한다. 새로운 지속 식별이나 서버 수집은 별도 개인정보 검토 후 도입한다.

예: 최초 완료 25명, 확인된 추천 신규 완료 5명이면 계수 0.2다. 예시 숫자이며 실제 성과가 아니다.
방문만 높고 시작이 낮으면 소개와 첫 화면을, 시작 대비 완료가 낮으면 녹음·질문 흐름을, 완료 후 추천이 없으면 결과에서 대화하고 싶은 이유를 살펴본다.
결제 안내 오노출이나 개인정보 안내 불일치가 있으면 추가 배포를 멈추고 먼저 고친다.

P0: 무료 약속과 서버 실제 제공 범위 일치, 초대→완료→재초대 경로 검증.
P1: 결과 직후 짧은 공유 카드와 친구 초대 CTA, 개인정보 숨김, 공유 취소·실패·완료의 가능한 범위 내 계측.
P2: 동일한 그룹 코드를 사용하는 동의 기반 모임 결과판. 현재 URL 스냅샷 방식과 구별하고 소규모 집단의 신원 노출을 방지한다.
